        How directory integration works

        1. 1

          LDAP connection

          A service account binds to the domain controller over LDAPS.

        2. 2

          User sync

          Accounts in the selected OUs are imported with name, email, department and manager.

        3. 3

          Single sign-on

          Integrated Windows authentication (Negotiate/Kerberos) signs employees in silently.

        4. 4

          Role mapping

          Security groups map to Admin, Manager and Employee roles.

        5. 5

          Automatic deprovisioning

          Disabled directory accounts lose access on the next sync.

        6. 6

          Scheduled sync

          A background job re-syncs on a fixed interval.
